# Stage 0: Frame
**Question:** Is this worth doing, and for whom?
**Skills:** interview-me, idea-refine, landscape-and-sizing

## Exit checklist
| Mode | Required outputs |
|---|---|
| new | `00-frame/brief.md` (problem, user, success metric, vision line), `00-frame/landscape.md` |
| revamp, feature, fix | Not used. Start at a later stage. |

## Gate questions
1. Is the problem real and painful for a specific user?
2. Is there a measurable success metric?
3. Why now, and why us?
**Decision owner:** the user. Go / Narrow / Stop / Pause.
