# Stage 5: Launch & Learn
**Question:** Did it move the metric, and what did we learn?
**Skills:** launch-plan, measure-setup, learn-readout, retro
**Also the entry point for fix/iterate mode** (start with learn-readout).

## Exit checklist
| Mode | Required outputs |
|---|---|
| new, revamp, feature | `05-launch/plan.md`, `05-launch/metrics.md`, `05-launch/readout.md` (statistical or labeled directional), `05-launch/retro.md`, `lessons.md` updated |
| fix | `05-launch/readout.md` that names the problem, then hands a fix spec to Define |

## Gate questions
1. Did the metric move? Is the result statistical or directional?
2. Which failures became new eval cases?
3. Which lessons get promoted to `learnings/`?
**Decision owner:** the user. Iterate (back to Define) / Scale / Stop / Pause.
