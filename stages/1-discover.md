# Stage 1: Discover
**Inputs:** `00-frame/brief.md` in new mode. `01-discover/current-product.md` in revamp and feature mode.
**Question:** What's true about the users and the market?
**Skills:** interview, feedback-mining, segments-personas, opportunity-solution-tree, assumptions-to-experiment

## Exit checklist
| Mode | Required outputs |
|---|---|
| new | `01-discover/insights.md` (from interviews or feedback), `01-discover/ost.md`, `01-discover/assumptions.md` (riskiest ones tested or planned) |
| revamp | `01-discover/current-product.md` (written by the router), `01-discover/insights.md` from existing data, `01-discover/ost.md`, `01-discover/assumptions.md` |
| feature | `01-discover/current-product.md` (written by the router), `01-discover/assumptions.md` (quick check only, about 15 minutes; then gate to Define) |
| fix | Not used |

## Gate questions
(Feature mode: passes only if the riskiest assumption has a test with a pass threshold set in advance. Otherwise flag it.)
1. Are insights backed by real evidence with sources?
2. Is the riskiest assumption tested, or knowingly accepted?
3. Is the target opportunity chosen? (new and revamp. In feature mode: is the feature request the right thing to build next?)
**Decision owner:** the user. Go / Narrow / Back / Stop / Pause.
