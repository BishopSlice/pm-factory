# Stage 3: Design
**Question:** What does it look and feel like?
**Skills:** design-brief, prototype, design-critique, design-polish

## Exit checklist
| Mode | Required outputs |
|---|---|
| new, revamp | `03-design/brief.md`, a working prototype, `03-design/critique.md` with no blocking issues |
| feature | Prototype of the changed screens, `03-design/critique.md` |
| fix | Skip unless the fix changes the UI. If it does: same as feature. |

## Gate questions
1. Can a new user finish the main task without help?
2. Are empty, error and loading states handled?
3. Did both critique reviewers clear it?
**Decision owner:** the user. Go / Narrow / Back / Pause.
